Quiet supports [PushFeedback](https://pushfeedback.com/) for per-page thumbs up and thumbs down.

:::note Paid plans
PushFeedback offers paid plans. Quiet users get a [30-day trial of Unlimited](https://pushfeedback.com/quiet), with no credit card required. For new accounts.
:::

## Configure feedback

If you already use `docusaurus-pushfeedback`, Quiet uses its project. Otherwise, provide the project ID and load the widget:

```js title="docusaurus.config.js"
export default {
  themes: [
    [
      "docusaurus-theme-quiet",
      {
        feedback: { project: "YOUR_PROJECT_ID" },
      },
    ],
  ],
  headTags: [
    {
      tagName: "link",
      attributes: {
        rel: "stylesheet",
        href: "https://cdn.jsdelivr.net/npm/pushfeedback/dist/pushfeedback/pushfeedback.css",
      },
    },
    {
      tagName: "script",
      attributes: {
        type: "module",
        src: "https://cdn.jsdelivr.net/npm/pushfeedback/dist/pushfeedback/pushfeedback.esm.js",
      },
    },
  ],
};
```

Replace `YOUR_PROJECT_ID` with your project's ID. Quiet does not load an SDK by itself. No project means no controls.

## Placement

Thumbs appear below the table of contents in the right sidebar. On mobile and pages without that sidebar, they appear below the document.

Change the label or keep them below the document on every screen:

```js
feedback: {
  project: "YOUR_PROJECT_ID",
  label: "Was this useful?",
  position: "footer",
},
```

Set `feedback: false` to remove them. Remove an old `DocItem/Footer` feedback override when adopting these controls, so the same form does not appear twice. Your copyright, page navigation and last-updated information remain intact.

## Verify

Check desktop and mobile placement, both color modes and accessible button names. Each thumb opens your feedback form with its rating selected. Submit tests only to a project intended for testing.
