title: Diagrams
description: Integrate Mermaid diagrams with text alternatives and matching theme colors.
---

Use Docusaurus's optional Mermaid theme. It reads the site's light and dark mode. Quiet keeps the surrounding typography and spacing consistent.

[Rendered examples and installation](/components/diagrams)

Keep diagrams small, label their connections and explain the flow in text. Avoid making an image the only record of prerequisites, an API or an operating procedure.
