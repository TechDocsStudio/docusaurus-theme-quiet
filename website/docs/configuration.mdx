## Theme options

| Option            | Type                | Default   |
| ----------------- | ------------------- | --------- |
| `accentColor`     | Six-digit hex color | `#191a18` |
| `accentColorDark` | Six-digit hex color | `#e9ecef` |
| `showCredit`      | Boolean             | `true`    |

Unknown options and invalid colors fail the build with an explanation.

```js
export default {
  themes: [
    [
      "docusaurus-theme-quiet",
      {
        accentColor: "#191a18",
        accentColorDark: "#e9ecef",
      },
    ],
  ],
};
```

## Footer credit

The footer shows **Powered by Quiet**, linked to [quiet.techdocs.studio](https://quiet.techdocs.studio), by default. It also appears when your site has no configured footer. Your existing footer links, logo and copyright are preserved.

To remove the credit:

```js title="docusaurus.config.js"
themes: [["docusaurus-theme-quiet", { showCredit: false }]];
```

## CSS tokens

| Token                   | Default                    | Use                       |
| ----------------------- | -------------------------- | ------------------------- |
| `--quiet-font-body`     | Inter, system fallback     | Reading text and controls |
| `--quiet-font-heading`  | Inter Tight, body fallback | Headings                  |
| `--quiet-font-logo`     | Heading font               | Navbar brand title        |
| `--quiet-font-code`     | System monospace           | Code                      |
| `--quiet-content-width` | `48rem`                    | Maximum article width     |
| `--quiet-radius`        | `8px`                      | Panels and controls       |
| `--quiet-paper`         | White / near black         | Page background           |
| `--quiet-surface`       | Light / dark gray          | Supporting surfaces       |
| `--quiet-ink`           | Near black / near white    | Main text                 |
| `--quiet-muted`         | Gray                       | Secondary text            |
| `--quiet-line`          | Light / dark border        | Dividers                  |

Use Docusaurus configuration for logos, navigation, sidebars, locales, versions, metadata and the footer. Quiet does not duplicate those settings.

## Compatibility

The first release targets Docusaurus 3.10.x, Classic, and React 18 or 19. The documentation site is built with 3.10.2 and React 18. Consumer validation records the versions actually tested.

Custom swizzles take precedence over a theme. Review existing CSS and overrides when adopting Quiet. OpenAPI and Mermaid remain separate plugins and themes.
