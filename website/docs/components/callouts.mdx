---
title: Callouts
description: Notes, warnings and errors using native Docusaurus admonitions.
---

Use a callout when it changes an action or prevents a mistake.

:::note
Restart the development server after changing the theme configuration.
:::

:::tip
Check both light and dark mode before releasing a custom color palette.
:::

:::warning
Changing document slugs can break existing links. Add redirects when a URL must change.
:::

:::danger
Never publish credentials in documentation or examples.
:::

```md
:::warning
Changing document slugs can break existing links.
:::
```

Custom titles use `:::note Your title`. Keep the title only when it adds meaning.
