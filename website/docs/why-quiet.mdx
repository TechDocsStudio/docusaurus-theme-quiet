---
title: Why Quiet
description: A minimal, opinionated Docusaurus theme that gives existing documentation components and integrations one consistent interface.
---

Quiet brings guides, API reference, search, AI assistance and page feedback into a consistent interface. Teams keep the tools that work for them and get one visual system around them.

## Small by design

The defaults favor readable text, compact controls and visible structure. Color identifies actions and state. Decorative elements and repeated labels stay out of the way.

## Built on existing tools

Quiet extends Docusaurus Classic. Routing, navigation, Markdown, accessibility controls and code behavior stay with the components that already provide them.

Search and Ask AI can use [Biel](./integrations/ask-ai.mdx), feedback can use [PushFeedback](./integrations/user-feedback.mdx), diagrams use [Mermaid](./integrations/diagrams.mdx), and API reference uses [Docusaurus OpenAPI Docs](./integrations/openapi.mdx). These integrations are optional. Quiet unifies their layout, typography and styling.

## Opinionated, configurable

Neutral surfaces, consistent type sizes and restrained controls are the starting point. Change the logo, fonts and accent colors through [Branding](./branding.mdx). Keep your own content, navigation and provider accounts.

## Used by

[Biel.ai](https://biel.ai) and [PushFeedback](https://pushfeedback.com) are the first documentation sites being adapted to Quiet. Their documentation is used to test guides, generated references, search and feedback.

## What we want to build

A dependable starting point for product documentation, with examples that can be copied and components that can be maintained. Each improvement should make the same page easier for readers, contributors and AI tools to use.
